## How to Use These Files

- **Before a design review**: Read `AGENT_PATTERN.md` to understand shared patterns already decided
- **Before a handoff to UI**: Read `UI.md` to understand how they receive and implement designs
- **Before a backend discussion**: Read `BACKEND.md` to understand constraints and APIs
- **Before writing specs for integration**: Read `INTEGRATION_PM.md` for the PM's current priorities
- **For framework/protocol questions**: Read `ARIA_FRAMEWORK.md`
